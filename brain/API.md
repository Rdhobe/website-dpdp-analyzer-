# API.md — API Reference

**Status:** The Python backend is a placeholder exposing only `GET /health`; the implemented product API is the Next.js audit API (`/api/audits/**`). The broader product API is not implemented.

The FastAPI service exposes a health check only; the single-page landing analyzer was removed on 2026-10-19. The audit API lives in the Next.js app under `app/api/audits/` (see section 7). Under the approved DEC-008 layout, these route handlers will eventually move to `src/app/api/`. Every endpoint in section 3 and later (other than section 7) is **Planned** based on the requirements and must not be called or documented as available.

## 2. Planned API Conventions

| Concern | Proposed convention |
| --- | --- |
| Style | REST over JSON |
| Base path | `/api` |
| Versioning | `TBD` (URL versioning or header) |
| IDs | UUID strings |
| Dates | ISO 8601 UTC |
| Auth | Bearer session/JWT or secure cookie (`TBD`) |
| Tenant scope | Derived from authenticated session, never from client-supplied tenant ID |
| Pagination | Cursor-based preferred; `limit` + `cursor`; bounded max |
| Filtering | Explicit allowlisted query params |
| Errors | Structured JSON: `{ "error": { "code", "message", "details", "request_id" } }` |
| Idempotency | Required for audit creation and export generation (`Idempotency-Key`) |
| Rate limits | Per user and per tenant; `429` with retry guidance |
| Live updates | SSE preferred for crawl progress; WebSocket acceptable |
| Content types | `application/json`; exports use `application/pdf`, `text/csv`, `application/json` |

**Standard error codes (proposed):** `unauthenticated`, `forbidden`, `not_found`, `validation_error`, `rate_limited`, `conflict`, `blocked_destination`, `crawl_limit_exceeded`, `auth_failed`, `internal_error`.

## 3. Planned Endpoints

> Implemented status for all: **Planned**. Route/file references are target locations, not existing files.

### 3.1 Projects

#### `POST /api/projects`

- **Purpose:** Create a website audit project.
- **Auth:** Required; tenant-scoped.
- **Body (proposed):**
  - `name` (string, required, bounded)
  - `root_url` (string, required, http/https, public destination)
  - `auth_mode` (`public` | `credentials` | `manual`)
  - `login_url` (string, optional)
  - `username`, `password` (optional; never returned)
  - `auth_instructions` (string, optional)
  - `max_depth`, `max_pages`, `max_concurrency`, `request_delay_ms`, `request_timeout_ms`
  - `same_origin_only` (boolean, default `true`)
  - `approved_subdomains` (string[], optional)
  - `include_paths`, `exclude_paths` (string[], optional)
  - `max_file_size_bytes`
  - `supported_content_types` (string[])
  - `javascript_rendering`, `screenshots`, `cookie_analysis`, `form_analysis`, `ai_analysis` (booleans)
  - `legal_framework_version` (string)
  - `organization_context` (object, optional)
  - `authorization_attested` (boolean, required `true`)
- **Responses:** `201` project; `400` validation; `401`; `403`; `422`.
- **Validation:** URL scheme/host, private/metadata blocking, numeric bounds, path syntax, credentials required only for credentials mode.
- **Rate limit:** Proposed.
- **Reference (target):** `backend/app/api/projects.py`.

#### `GET /api/projects`

- **Purpose:** List tenant projects.
- **Auth:** Required.
- **Query:** `limit`, `cursor`, `status`, `search`.
- **Responses:** `200` list; `401`.
- **Reference (target):** `backend/app/api/projects.py`.

#### `GET /api/projects/{project_id}`

- **Purpose:** Retrieve project configuration and latest audit summary.
- **Auth:** Required; tenant membership.
- **Responses:** `200`; `404` (also for unauthorized to avoid enumeration); `401`.
- **Reference (target):** `backend/app/api/projects.py`.

#### `PATCH /api/projects/{project_id}` (proposed, not in requirements list)

- **Purpose:** Update configuration (not credentials).
- **Auth:** Required.
- **Responses:** `200`; `400`; `403`; `404`; `409` if an audit is running.
- **Status:** Proposed addition, not explicitly in the requirements endpoint list. Needs approval.

#### `DELETE /api/projects/{project_id}` (proposed)

- **Purpose:** Soft-delete project and schedule artifact purge.
- **Auth:** Required.
- **Responses:** `204`; `403`; `404`; `409` if an audit is running.
- **Status:** Proposed addition.

### 3.2 Audits

#### `POST /api/projects/{project_id}/audits`

- **Purpose:** Start a new audit run for a project.
- **Auth:** Required; tenant membership; authorization attestation.
- **Body (proposed):** `legal_framework_version`, `ai_enabled` (optional override), `checks` (optional subset for re-check).
- **Responses:** `202` with `audit_id`; `400`; `403`; `404`; `409` if an audit is already running; `422`.
- **Side effects:** Creates audit + crawl job; enqueues work.
- **Idempotency:** Recommended.
- **Reference (target):** `backend/app/api/audits.py`.

#### `GET /api/audits/{audit_id}`

- **Purpose:** Audit summary, status, configuration snapshot, counts, coverage.
- **Auth:** Required; tenant membership.
- **Responses:** `200`; `403`; `404`.
- **Reference (target):** `backend/app/api/audits.py`.

#### `GET /api/audits/{audit_id}/progress`

- **Purpose:** Live or polled crawl progress.
- **Auth:** Required.
- **Response (proposed):**
  ```json
  {
    "audit_id": "uuid",
    "status": "running",
    "current_url": "https://example.com/about",
    "queue_depth": 42,
    "discovered": 120,
    "processed": 75,
    "failed": 3,
    "skipped": 10,
    "retries": 2,
    "last_event_at": "2026-10-19T10:00:00Z"
  }
  ```
- **Rules:** No invented percentage or ETA. Progress reflects real counts.
- **Live channel:** Proposed SSE `GET /api/audits/{audit_id}/events` or WebSocket. The requirements specify WebSockets or SSE but not a concrete path.
- **Responses:** `200`; `403`; `404`.
- **Reference (target):** `backend/app/api/audits.py`.

#### `POST /api/audits/{audit_id}/pause`

- **Purpose:** Pause a running audit.
- **Auth:** Required.
- **Responses:** `202`; `409` if not running; `403`; `404`.
- **Reference (target):** `backend/app/api/audits.py`.

#### `POST /api/audits/{audit_id}/resume`

- **Purpose:** Resume a paused audit.
- **Auth:** Required.
- **Responses:** `202`; `409`; `403`; `404`.
- **Reference (target):** `backend/app/api/audits.py`.

#### `POST /api/audits/{audit_id}/cancel`

- **Purpose:** Cancel an audit and clean up sessions/credentials.
- **Auth:** Required.
- **Responses:** `202`; `409`; `403`; `404`.
- **Side effects:** Stop queue processing; destroy browser session/profile; preserve completed evidence per retention.
- **Reference (target):** `backend/app/api/audits.py`.

#### `POST /api/audits/{audit_id}/recheck`

- **Purpose:** Re-run selected checks or the entire audit.
- **Auth:** Required.
- **Body (proposed):** `checks` (optional array); omit to re-run all.
- **Responses:** `202` with new audit/run reference; `400`; `403`; `404`; `409`.
- **Reference (target):** `backend/app/api/audits.py`.

#### `GET /api/audits/{audit_id}/pages`

- **Purpose:** List discovered pages and crawl status.
- **Auth:** Required.
- **Query:** `limit`, `cursor`, `status`, `page_type`, `authenticated`, `has_findings`, `search`.
- **Response item (proposed):** id, url, page_type, http_status, status, authenticated, findings_count, last_crawled_at, error_reason.
- **Responses:** `200`; `403`; `404`.
- **Reference (target):** `backend/app/api/pages.py`.

#### `GET /api/audits/{audit_id}/findings`

- **Purpose:** List findings with filters.
- **Auth:** Required.
- **Query:** `limit`, `cursor`, `severity`, `status`, `category`, `review_status`, `assigned_reviewer`, `search`.
- **Responses:** `200`; `403`; `404`.
- **Reference (target):** `backend/app/api/findings.py`.

#### `GET /api/audits/{audit_id}/report`

- **Purpose:** Assemble report data (and/or trigger/view report metadata).
- **Auth:** Required.
- **Responses:** `200`; `403`; `404`; `409` if audit incomplete (policy `TBD`).
- **Reference (target):** `backend/app/api/reports.py`.

#### `GET /api/audits/{audit_id}/export`

- **Purpose:** Download PDF, JSON, or CSV export.
- **Auth:** Required.
- **Query:** `format` (`pdf` | `json` | `csv`), optional `sections`.
- **Responses:** `200` file stream with correct content type; `202` if generation async; `400` unsupported format; `403`; `404`; `429`.
- **Rules:** Secrets and sensitive values redacted; reproducible from audit ID.
- **Reference (target):** `backend/app/api/reports.py`.

### 3.3 Findings

#### `GET /api/findings/{finding_id}`

- **Purpose:** Retrieve full finding with evidence, affected URLs, legal references, remediation, and review state.
- **Auth:** Required; tenant membership.
- **Responses:** `200`; `403`; `404`.
- **Reference (target):** `backend/app/api/findings.py`.

#### `PATCH /api/findings/{finding_id}`

- **Purpose:** Update review status, assign reviewer, add resolution notes. Does not alter evidence or legal references.
- **Auth:** Required; reviewer permission.
- **Body (proposed):** `review_status`, `assigned_reviewer_id`, `resolution_notes`.
- **Responses:** `200`; `400`; `403`; `404`; `409` on concurrent update.
- **Reference (target):** `backend/app/api/findings.py`.

## 5. Authentication and Authorization Requirements

- All endpoints except registration/login/health require authentication.
- Object-level authorization on every project, audit, page, finding, report, and artifact.
- Return `404` instead of `403` where revealing resource existence is risky.
- CSRF protection for cookie-based state-changing requests.
- Rate limiting per user/tenant; stricter limits for audit creation and exports.
- Log authorization denials with correlation IDs.

## 7. Implemented TypeScript Audit Endpoints (2026-10-19)

Implemented inside the Next.js app under `dpdp-compliance-auditor/app/api/audits/`. These routes are **not authenticated and not tenant-scoped yet**, and long crawls run in a detached worker process (`workers/audit-worker.ts`); the `POST` handler only records a queued run.

| Method | Path | File | Request | Response | Status |
| --- | --- | --- | --- | --- | --- |
| POST | `/api/audits` | `app/api/audits/route.ts` | `{ url, authorized: true, browserEnabled?, screenshots?, notes? }` (Zod-validated) | `202` queued `AuditRun`; `400` for invalid/unsafe targets | Implemented |
| GET | `/api/audits` | `app/api/audits/route.ts` | none | `{ audits: AuditListItem[] }` | Implemented |
| GET | `/api/audits/{id}` | `app/api/audits/[id]/route.ts` | none | full `AuditRun` or `404` | Implemented |
| POST | `/api/audits/{id}/credentials` | `app/api/audits/[id]/credentials/route.ts` | `{ username, password }` (Zod-validated; max 200/500 chars) | `202` `{ id, status }` for a new queued run; `404` unknown run; `409` run is queued/running or detected no login; `400` invalid body | Implemented |
| GET | `/api/audits/{id}/export?format=json\|csv\|pdf` | `app/api/audits/[id]/export/route.ts` | `format` query parameter (default `json`) | file download or `404` | Implemented |
| GET | `/api/audits/{id}/screenshots/{name}` | `app/api/audits/[id]/screenshots/[name]/route.ts` | path `name` (validated `*.png`) | `image/png` or `404` for missing/unsafe names | Implemented |

Example response from `POST /api/audits` (shortened):

```json
{
  "id": "audit_<uuid>",
  "status": "queued",
  "targetUrl": "https://example.com/",
  "createdAt": "2026-10-19T10:00:00.000Z",
  "tests": [],
  "findings": [],
  "findingGroups": [],
  "summary": null
}
```

Notes:

- A completed `AuditRun` includes `findingGroups` (consolidated findings, see [DEC-015](./DECISION.md)), and each `TestResult` carries a `claimType` plus `summary.coverage` (four independent measures, see [DEC-017](./DECISION.md)). Runs also carry `auth` (`null` for public crawls, otherwise login-wall/authentication metadata; never credential values).
- `GET /api/audits/{id}/export?format=csv` includes a `claimType` column and a JSON `evidence` column; the PDF includes the full structured evidence, consolidated groups, coverage measures and per-provision legal dates (see [DEC-018](./DECISION.md)).
- `url` must be `http`/`https`, must not contain embedded credentials, and is resolved and checked against private/reserved address ranges before crawling.
- There is no `maxPages`/`maxDepth`; crawls follow same-site links until the queue empties or a fixed 5-minute engine budget (`ENGINE_TIME_BUDGET_MS`) expires. `notes` is bounded to 500 characters.
- A run whose start page is a login wall finishes as `requires_credentials` (no tests) with `auth = { loginWallDetected, loginSurfaceDetected, loginUrl, authenticated: false, failureReason }`. A run whose start page is public but whose crawl reaches a login page finishes normally with `auth.loginSurfaceDetected: true` and offers an optional authenticated run. Posting credentials creates a new run for the same target/config; the endpoint accepts any run that is not `queued`/`running` and whose `auth` detected a login wall or surface. Credentials are streamed to the worker over stdin and are never stored, logged, or returned. Only a single-step username/password form is supported (no MFA/CAPTCHA/SSO). See [DEC-020](./DECISION.md), [DEC-021](./DECISION.md), and [DEC-022](./DECISION.md).
- The dashboard polls `GET /api/audits/{id}` every 1.5 seconds until the run reaches `completed`, `failed`, `partial`, or `requires_credentials` (`components/audit/audit-live.tsx`). While queued/running the response includes `progress: AuditProgressEntry[]` — timestamped `{ at, level, message, url?, attempted?, succeeded?, failed?, pending? }` entries capped at the last 400 — plus `auth.diagnostics` when a sign-in was attempted.
- `screenshots` is a boolean audit option. When enabled (default in the UI), the worker captures a full-page screenshot and element crops of the consent interface, privacy/cookie/terms links, contact/grievance link, forms, and primary heading for each crawled page. Screenshot names are generated and validated (`^[A-Za-z0-9][A-Za-z0-9._-]*\.png$`, no `..`); the serving route rejects traversal and returns `404`.
- No authentication, authorization, rate limiting, or tenant isolation is implemented; see [SECURITY.md](./SECURITY.md).
